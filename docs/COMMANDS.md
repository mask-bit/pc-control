# Comandos

## Apps e sites

```text
abre o Chrome
abre o Word
abre YouTube
abre Gmail
abre documentos
abrir Chrome e Spotify
abrir WhatsApp e depois tocar lo-fi
fechar Spotify
```

## Pesquisa

```text
pesquisa clima
pesquisa Python no Google
procura tutorial de Vosk
pesquisar lo-fi no YouTube
abrir videos de musica ambiente no YouTube
```

## Spotify

```text
toca lo-fi
toca playlist foco
pausa Spotify
proxima musica
musica anterior
aumenta volume
abaixa volume
volume para 30
```

## Rotinas

```text
ativar modo estudo
modo estudo
criar rotina pelo painel
```

## Sistema

```text
volume para 30
copia texto exemplo
listar comandos
confirmar
cancelar
```

## IA opcional

Com OpenAI configurada, o app tambem entende pedidos mais vagos:

```text
abre YouTube e coloca musica para estudar
resume esse texto
me explica isso de forma simples
cria uma ideia de rotina de foco
```

Sem OpenAI, os comandos essenciais continuam funcionando pelo parser local.

## Customizacao

Edite `assistant_config.json` para adicionar:

- nomes de apps;
- sites favoritos;
- pastas;
- playlists;
- rotinas.
