# Comandos

## Apps e sites

```text
abre o Chrome
abre o Word
abre YouTube
abre Gmail
abre documentos
```

## Pesquisa

```text
pesquisa clima
pesquisa Python no Google
procura tutorial de Vosk
```

## Spotify

```text
toca lo-fi
toca playlist foco
pausa Spotify
proxima musica
musica anterior
aumenta volume
abaixa volume
```

## Rotinas

```text
ativar modo estudo
modo estudo
```

## Sistema

```text
volume para 30
copia texto exemplo
listar comandos
confirmar
cancelar
```

## Customizacao

Edite `assistant_config.json` para adicionar:

- nomes de apps;
- sites favoritos;
- pastas;
- playlists;
- rotinas.
